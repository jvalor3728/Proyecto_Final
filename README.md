# 🥿 Venta de Zapatos - Proyecto Final (React + Vite)

Este es un proyecto web desarrollado con **React + Vite** como parte del curso de Interfaces.  
Simula una tienda virtual donde el usuario puede ver, filtrar y comprar diferentes tipos de zapatos.

---

## 🎯 Funcionalidades principales

- ✅ Filtros por marca y talla
- ✅ Vista detallada de cada zapato
- ✅ Agregar y eliminar productos del carrito
- ✅ Simulación de pago con tarjeta
- ✅ Contador visible de productos en el carrito
- ✅ Fondo personalizado y diseño responsivo

---

## ⚙️ Tecnologías usadas

- React
- Vite
- React Router DOM
- CSS puro
- JSON como base de datos local (`zapatos.json`)
